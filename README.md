The site introduces my work in German and English: a short profile, skills, selected projects with previews, references, and a contact form. Featured projects are Videoflix, Join, and Cavernwake, each with a live demo and the matching GitHub repository.

## Stack

Angular 20 · TypeScript · SCSS · RxJS · Transloco

## Development

```bash
npm install
ng serve
```

Open http://localhost:4200/. The app reloads when source files change.
